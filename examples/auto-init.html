SmeduverseAI Widget - Auto Init

This example uses data-smeduverse-ai attribute for automatic initialization.

No JavaScript code required - just add the data attributes to your container!

Usage:

<div 
  data-smeduverse-ai
  data-api-endpoint="http://localhost:3000/api/chat"
  data-mcp-key-endpoint="http://localhost:2222/mcp/key"
  data-position="bottom-right"
  data-title="My AI Assistant"
></div>
